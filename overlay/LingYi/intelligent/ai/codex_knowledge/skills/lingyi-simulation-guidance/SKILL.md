# 灵弈推演指导

本文件由人类维护，作为当前仿真智能体的规划指导。下列内容是初始运行指导；具体战略目标以本局任务简报为准。

- 先明确本局怎样得分、占领、守住或阻止对方，再比较各项部署对这些目标的贡献。出动数量本身不是目标。
- 抽调已有任务兵力前比较原任务价值、新任务收益和剩余时间；区分主要投入、掩护与预备力量。
- 根据已知机型、挂载、位置和状态安排适任任务。任务名称或目标描述不能替代平台能力依据。
- 设置区域和目的地时考虑目标位置、预计到达时机、有效在位时间及对占领任务的影响；无足够信息时说明判断条件。
- 复用游戏操作经验时写清选择哪些单位、任务类型、目标或区域、编组、挂载及改变部署的时机。区分已验证操作与待试打法。
- 反思聚焦指挥决策、战略战术与游戏操作。未到位兵力只作为战局约束，不展开框架、模型或代码诊断。
- 起飞不等于抵达或完成任务。引用历史经验时检查想定、兵力、时间与情报是否相符；单局胜负不能证明某项打法有效。

人类可在此补充具体经验，每条写清适用条件、建议、例外和判断依据。自动反思保存在 experience 中，不自动改写本文件。
